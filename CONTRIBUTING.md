# Contributing

Open an issue for a policy clarification, missing trigger,
or broken reference. Use the documentation label for wording
and policy discussions and the bug label for a broken index
or selector. The help wanted label identifies a concrete
task accepting contributions.

Keep one concern per change. A standard needs a stable
identifier, a matching kebab-case filename, a clear
situation in standards/index.json, and portable guidance.
Keep organization-specific configuration and private
incident details out of examples.

Run python3 scripts/check.py. If changing selection
behavior, include a case that distinguishes the intended
result from the previous behavior. Update generated demo
assets only through their documented generator.

Keep claims tied to evidence. Clearly distinguish prose
guidance from automated enforcement and measured outcomes.
