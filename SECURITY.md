# Security

Report a suspected credential exposure or security problem
privately using this repository's
[GitHub vulnerability reporting form](https://github.com/trycopilotai/agent-standards/security/advisories/new).
Avoid including sensitive material in public issues.

The standards are guidance. Their presence does not enforce
permissions or guarantee that an agent follows them. The
selector reads only the packaged index and prints relative
paths. Review local instructions and commands before
adopting them in your environment.
