# Pull Request Review Handoff

Hand over a concrete, review-ready change with a title and
description that explain the final behavior. Run the
required checks and attach evidence before asking for
review.

When the operator requests a browser handoff, open the
correct pull request using the host's supported launcher.
Use the browser or application selected by the operator. In
headless contexts, provide the direct usable review URL.

Do not hand over a draft as ready or interrupt an imminent
authorized automatic merge with a redundant browser launch.
Distinguish a request for human review from a change that
the agent is already authorized to land.

If several changes must land in order, identify the
dependency and present the relevant review links together.
State remaining required operator action precisely; do not
turn a status update into a vague standing offer.
