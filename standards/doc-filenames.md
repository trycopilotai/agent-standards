# Document Filenames

Use a consistent, discoverable convention for authored
reference documents. This collection uses kebab-case names
paired with each standard's index identifier. Tool-required
names such as README.md, AGENTS.md, and CONTRIBUTING.md keep
their required spelling.

Choose names for the document's subject and audience. Avoid
internal workspace labels, agent-authorship markers, and
unrelated company names in public filenames or metadata.

Respect established exceptions: source files follow their
language, workflow files follow their tool, and dated plans
or run records follow the repository's state convention.

Rename only within the authorized scope. Update inbound
links, index entries, scripts, and generated references in
the same change. On case-insensitive filesystems, use an
intermediate name for a case-only rename and verify Git's
recorded path.
