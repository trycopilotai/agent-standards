# Evidence

No measurements of agent compliance, productivity,
reliability, or security outcomes were collected.

The selection transcript records a real invocation of the
local selector on a synthetic prompt. Its manifest records
the input commit, script hash, Python version, command,
invocation date, output hash, and whether editing occurred.
No private task data is used in that prompt.

The check validates index coverage, identifiers, relative
paths, local Markdown file links, release version, selector
cases, and demo dimensions and looping. It does not execute
the operational commands described by the prose or prove
that an agent obeys them.

The demo is a reconstructed visualization of the committed
selection transcript. To rebuild the demo, poster, and 1280
by 640 social preview, install Pillow 11.3.0 and run:

```sh
python3 scripts/build_assets.py
```

The generator uses Pillow's bundled default TrueType font.
No system fonts or external images are required. The check
itself uses only Python's standard library.
